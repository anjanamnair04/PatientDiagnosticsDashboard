The Patient symptom dataset consisting of 19903 rows and 15 columns is the central fact table. It provides detailed information about each patient visit, including demographics, vital signs, symptoms, chronic condition indicators, and clinical outcomes.
 ## Objective
Develop a patient diagnostic dashboard combining symptoms, chronic conditions, and visit patterns to support faster and clearer clinical insights.
## What the Dashboard Helps With  
The dashboard enables healthcare professionals to:
* Spot possible fever or illness patterns
* Check overall patient risk level
* Monitor chronic conditions (BP, Diabetes, Thyroid, Liver, Asthma)
* Compare current vs previous diagnostic reports
* Analyze patient visit frequency and gaps
* Track patient health trends over time
* Review medication usage for awareness
## Tool Used
* PowerBi
## Tasks Performed
* Generated tables based on the given sample data using the AI prompts.
* Transformed the data using power query editor and loaded into PowerBi desktop for analysis.
* Created necessary calculated columns and measures using DAX and M languages.
